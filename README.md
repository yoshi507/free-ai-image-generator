# PixelForge — Free AI Image Generation API ✨

A professional, free AI image generation platform with its own API keys.

## Features

- 🎨 Beautiful image generation (unlimited & free)
- 🔑 **Create your own API keys** to use in external projects
- 📚 Full API documentation
- 🕘 Local generation history
- 🔐 Ready for real Email / Magic Link login + server-side keys (via Supabase)
- 📱 Fully responsive professional UI

## Who generates the images?

Images are generated by **Pollinations.ai** — a free open community service running models like Flux.  
No paid API keys are required, which is why everything stays free.

## Quick Start (Local)

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel (Free)

1. Push to GitHub (already done)
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the repo → Deploy
4. You get a free `*.vercel.app` URL

## Using the API in your own projects

```bash
curl -X POST https://YOUR-DOMAIN.vercel.app/api/v1/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk_live_your_key" \
  -d '{"prompt": "a cute robot cat, highly detailed"}'
```

## Enable Real Email Login + Persistent API Keys

1. Create a free project at [supabase.com](https://supabase.com)
2. Authentication → Providers → enable Email (supports magic link + password)
3. Create two tables (`api_keys`, `generations`)
4. Add these environment variables in Vercel:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. Redeploy

The code is already prepared for Supabase — once the env vars are set it will activate.
